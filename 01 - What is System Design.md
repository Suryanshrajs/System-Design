✍️ What is System Design?
System design is the process of designing the different elements of a system. Think of a large application; system design is the procedure of defining its elements.

System design is the process of designing different elements of a system

Elements include the architecture of the application, its modules, interfaces, and how data flows between these different elements. The process of defining all these elements is system design.

📑 Types of System Design
There are two types of system design:

High-Level Design (HLD)
Low-Level Design (LLD)
⏫ High-Level Design
Describes a medium in components developed for the resultant product (application).

HLD involves describing the main components developed for the resultant application.

⏬ Low-Level Design
Describes internal logic of each of the components.

LLD involves describing the internal logic of each of the components. It includes architectural details, relationships between components, and business logic implementation details. LLD focuses on actual implementation.
