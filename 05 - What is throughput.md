## **🚀 Throughput**

**Throughput** is the measure of the amount of work or information processed by a system over a period of time. It indicates how much a system is accomplishing.

> Throughput = Data Transmitted / Unit of Time. It is also defined as Process Flow Rate
> 

For example, "I am making a video every day. I made 100 videos in 100 days." In this case, your throughput is one video per day.

### **🤔 Throughput in Distributed Systems**

In **distributed systems**, components are often dispersed, which can affect throughput differently than in a single codebase system.

- **Single System:** A single system has one code base, elements are closely tied, so dividing up tasks is limited
- **Distributed System:** Distribution involves breaking down tasks among different components.
    - **Increased Resources:** A distributed system has more resources available.
    - **Load Balancers:** Load balancers can be used to distribute incoming requests across multiple machines.
    - **No Limit on Resources:** Distributed systems can scale by adding more machines.

### **📉 Factors Reducing Throughput**

Several factors can reduce throughput in a system:

- **Latency:** Increased latency can reduce throughput.
    
    > Latency is defined as the time it takes for a request to be processed and a response to be received.
    > 
- **Protocol Overhead:** Communication overhead between servers reduces throughput. For example, frequent back-and-forth communication, like handshaking, increases latency.
- **Congestion:** Too many requests at once lead to congestion, decreasing throughput.

### **📈 Improving Throughput**

Methods to improve throughput include:

- **DM (Data Management):** Refers to efficient data handling and optimization.
- **Caching:** Implement caching mechanisms.
- **Distilled System:** Create a distilled system.
- **Institute of Monoradhik Architecture Load Balancer:** Using load balancers.
- **Scaling Resources:** Upgrade resources.
